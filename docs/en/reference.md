# Full Reference

## Native Functions (Built-ins)

| Function | English | Portuguese |
| :--- | :--- | :--- |
| Length | `size(v)` | `tamanho(v)` |
| String | `text(v)` | `texto(v)` |
| Number | `number(v)` | `numero(v)` |
| Type | `type(v)` | `tipo(v)` |
| List Insert | `insert(l, i)` | `inserir(l, i)` |
| List Remove | `remove(l, idx)` | `remover(l, idx)` |
| Substring | `substring(t, i, f)`| `subtexto(t, i, f)` |
| Find | `find(t, s)` | `procurar(t, s)` |
| Object Keys | `keys(obj)` | `chaves(obj)` |
| Round | `round(n)` | `arredondar(n)` |
| Absolute | `abs(n)` | `absoluto(n)` |
| Set UI | `set(id, v)` | `definir(id, v)` |

## Multilingual Aliases

I-NOC normalizes the following terms:

*   `true` = `verdadeiro`
*   `false` = `falso`
*   `if` = `se`
*   `else` = `senão` / `£`
*   `and` = `e`
*   `or` = `ou`
*   `not` = `não`
