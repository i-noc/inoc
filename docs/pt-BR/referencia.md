| :--- | :--- | :--- |
| Comprimento | `tamanho(v)` | `size(v)` |
| Texto | `texto(v)` | `text(v)` |
| Número | `numero(v)` | `number(v)` |
| Tipo | `tipo(v)` | `type(v)` |

## Aliases Multilíngue

A I-NOC normaliza os seguintes termos:

*   `verdadeiro` = `true`
*   `falso` = `false`
*   `se` = `if`
*   `senão` = `else` / `£`
*   `e` = `and`
*   `ou` = `or`
*   `não` = `not`
